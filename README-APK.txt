PENTING FIRESTORE:
Deploy firestore.rules ke Firebase Console sebelum memakai fitur wallet/live chat.

BUILD APK:
Buka folder project ini di Android Studio lalu Build > Generate App Bundle / APK > Generate APK.

LAGU CUSTOM:
Masukkan file lagu bernama custom.mp3 ke app/src/main/assets/ agar tombol MUSIC dapat memutarnya.
